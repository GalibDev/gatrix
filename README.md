# 🌟 Why GATRIX?

GATRIX is more than a club website.

It is a complete digital ecosystem that helps robotics teams showcase innovation, manage content, publish announcements, display projects, highlight achievements, and connect with students through a modern user experience.

The project focuses on:

* Beautiful UI/UX
* Fast performance
* Scalability
* Easy administration
* Mobile responsiveness
* Modern development practices

# ⚙ Installation

```bash id="inst1"
git clone https://github.com/GalibDev/gatrix.git

cd gatrix

npm install

npm run dev
```
